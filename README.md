# Product-form feature allocation models
This repository contains the code for fitting the novel models proposed in the paper:
Lorenzo Ghilotti, Federico Camerlenghi, Tommaso Rigon (2025). Bayesian analysis of product feature allocation models. *Journal of the Royal Statistical Society Series B: Statistical Methodology* [journal](https://doi.org/10.1093/jrsssb/qkaf058})
Additionally, it contains data and code for replicating the simulation study and the applications.

The script "main.R" shows an example of the use of the available routines.
